# デバッグ

## 内蔵 Node.js デバッガ

`.js` / `.mjs` / `.cjs` ファイルは内蔵デバッガで実行します（`node --inspect-brk` + V8 Inspector）。Node.js のインストールが必要です。

## 外部 DAP アダプタ

その他の言語は、Debug Adapter Protocol（DAP）サーバーをワークスペースの `.touwa/debug.json` に登録するとデバッグできます。

```json
{
  "adapters": [
    {
      "id": "python",
      "command": "python",
      "args": ["-m", "debugpy.adapter"],
      "extensions": [".py"]
    }
  ]
}
```

| フィールド | 説明 |
| --- | --- |
| `id` | アダプタの識別子（重複不可、最大64文字） |
| `command` | PATH 上の実行ファイル名（パスは指定できません） |
| `args` | 起動引数（任意、最大32個） |
| `extensions` | 対象拡張子（`.py` 形式、最大16個） |

- 登録は最大10件までです。検証は Main で行い、不正なファイルがある場合はエラーを表示します。
- 対象ファイルの拡張子に一致するアダプタがあれば外部デバッグ、なければ内蔵デバッガ（Node.js ファイルのみ）を使います。どちらにも該当しない場合は開始できません。
- 起動時にアダプタへ渡す引数は `program`（対象ファイルの絶対パス）、`cwd`（ワークスペース）、`stopOnEntry: false` の汎用セットのみです。アダプタ固有の起動オプションには対応しません。
- ブレークポイント、ステップ実行、コールスタック、変数表示は内蔵デバッガと同じ Debug パネルで操作します。
- アダプタの逆リクエスト（runInTerminal など）には対応しません。
