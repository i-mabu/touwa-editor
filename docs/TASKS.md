# タスク

ワークスペースの `.touwa/tasks.json` にタスクを定義すると、Tasks パネル（アクティビティバーの TK、またはコマンドパレットの「View: Show Tasks」）から実行できます。

## 書式

```json
{
  "tasks": [
    { "label": "test", "command": "npm", "args": ["test"] },
    { "label": "build", "command": "npm", "args": ["run", "build"], "cwd": "." }
  ]
}
```

| フィールド | 必須 | 説明                                                                             |
| ---------- | ---- | -------------------------------------------------------------------------------- |
| `label`    | ○    | パネルに表示する名前。重複不可、最大100文字                                      |
| `command`  | ○    | 実行ファイル名のみ（PATH で解決）。パスや区切り文字は使えません                  |
| `args`     | ○    | 引数の配列（最大64個）。シェルを経由しないため、パイプやリダイレクトは使えません |
| `cwd`      | －   | 作業ディレクトリ（ワークスペース相対）。既定はルート（`.`）                      |

タスクは最大20件までです。書式が不正な場合は、パネルに理由を表示してタスクを一切読み込みません。

## 実行と安全

- タスクは **実行ボタンを押したときだけ** 動きます。フォルダを開いたときに自動実行されることはありません。
- 実行は Main プロセスの共通プロセス実行サービス経由で、`shell: false`、argv 配列、ワークスペース境界内の cwd、タイムアウト120秒、stdout / stderr 分離（各1MBまで）です。
- 結果はパネルに終了コードと所要時間、stdout / stderr を表示します。実行中に止める機能はまだありません（タイムアウトで終了します）。
- `tasks.json` はワークスペース内のファイルです。他人のリポジトリを開いた場合は、中身を確認してから実行してください。
